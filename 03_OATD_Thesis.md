# OATD / Open-Access Thesis (Literature Backbone)

> **OATD = Open Access Theses and Dissertations** (https://oatd.org).

## How to pull the thesis on OATD
1. Go to **https://oatd.org**
2. Search any of:
   - `cooperative adaptive cruise control string stability`
   - `vehicle platooning control thesis`
   - `connected automated vehicle longitudinal control`
3. Filter year ≥ 2015 and download the free PDF. TU Eindhoven (Ploeg/Nijmeijer group), KTH,
   UC Berkeley PATH, and TU Delft have many open platooning theses.

## Verified open-access works to use right now
1. **"Cooperative Adaptive Cruise Control: Network-Aware Analysis of String Stability"** — open
   access (ResearchGate / IEEE T-ITS author copy); directly on your topic.
2. **"Stochastic Lp string stability analysis in predecessor-following platoons under packet
   losses"** — open access, arXiv:2403.11043 (delay/packet-loss robustness reference).
   PDF: https://arxiv.org/pdf/2403.11043
3. **"Adaptive Cruise Control in Autonomous Vehicles: Challenges, Gaps, Comprehensive Review,
   and Future Directions"** — open access, arXiv:2510.03300 (Related-Work survey).

> Transparency note: OATD blocks automated fetching, so these were verified via open repos. Use
> the OATD search terms to attach a formal university thesis to your reference list.
