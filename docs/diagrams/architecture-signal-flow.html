§2 The distributed backend — one OS process per vehicle

Same control law, re-hosted as real ROS 2 nodes. Every arrow below is a message published on a named topic over DDS — a genuinely different communication mode: separate processes, separate clocks, no shared memory, no guarantee of delivery order without QoS policy. Vehicle nodes import §1's Systems 1–2 verbatim, so the control law itself is never duplicated.

What this buys, and what it costs: cross-validated against the offline core to within a few percent per hop (noiseless per-hop L2 ratios 0.976–0.996 in ROS vs. a uniform 0.9973 offline) — the gap is timing, not modeling. Not yet built: Systems 8–11 (the estimator/predictor/adapter of §1's right lane) are not ported into these nodes — today's distributed run validates the fixed-headway base controller only, not the adaptive or Flagship layers (Workstream A, 10_Handoff_Plan.md §3).
